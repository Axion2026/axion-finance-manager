# Axion Finance Manager

A clean and scalable Python-based system for managing small to medium business finances.  
This project is designed with a strong focus on **modularity, readability, and real-world usability**.

---

## 🚀 Features

- 📊 Income & Expense Tracking  
- 👥 Customer Management  
- 🏢 Supplier Management  
- 💳 Payment Monitoring  
- 📈 Financial Overview (planned)  

---

## 🧠 Project Goals

- Build a real-world financial management system  
- Apply **Object-Oriented Programming (OOP)** principles  
- Design a clean and maintainable architecture  
- Prepare the system for future expansion (GUI / Web App)

---

## 🛠️ Tech Stack

- **Python 3**
- **SQLite** (planned for persistent storage)
- Modular architecture (Models, Services, Data layer)

---
